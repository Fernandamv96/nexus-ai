# Política de seguridad

## Versiones soportadas

Este es un proyecto de portafolio/educativo. Solo la rama `main` recibe correcciones.

## Cómo reportar una vulnerabilidad

**No abras un issue público.** Usa uno de estos canales privados:

1. **GitHub Private Vulnerability Reporting**: pestaña *Security* → *Report a vulnerability*.
2. **Correo**: [correo eliminado] con el asunto `[SECURITY] <nombre del repo>`.

Incluye, si puedes:

- Descripción del problema y su impacto.
- Pasos para reproducirlo (o una prueba de concepto).
- Versión / commit afectado.

## Qué puedes esperar

- Confirmación de recepción en un plazo de **5 días hábiles**.
- Una evaluación inicial y, si corresponde, un plan de corrección.
- Crédito en el commit o en las notas del cambio, si lo deseas.

Gracias por ayudar a mantener este proyecto seguro.
